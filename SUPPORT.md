# Support

Thanks for using LangDeep.

## Where to ask questions

Use GitHub Discussions for:

- usage questions
- architecture discussions
- integration ideas
- provider/backend suggestions
- examples and deployment patterns

Use GitHub Issues for:

- reproducible bugs
- feature requests with clear scope
- documentation problems
- CI or packaging problems

## Before opening an issue

Please check:

1. The README and developer guide.
2. Existing open and closed issues.
3. Whether the problem reproduces on the latest `main` branch.
4. Whether a minimal no-network reproduction can be provided.

## Bug reports

A good bug report includes:

- LangDeep version or commit SHA
- Python version and OS
- minimal reproduction code
- full traceback or logs
- expected behavior
- actual behavior

## Security issues

Do not report security vulnerabilities through public issues. See `SECURITY.md`.

## Commercial or private support

LangDeep does not currently provide a formal commercial support program. Enterprise users should evaluate the framework carefully and provide clear issues or discussions when proposing production-related improvements.
